Organização de documentos de clientes

Padrão de nomenclatura

Todo arquivo de cliente segue o padrão: Sobrenome_Nome_TipoDeDocumento_Data (ex.: Silva_Ana_CertidaoNascimento_2026-08.pdf). Isso evita duplicidade e facilita localizar o arquivo certo rapidamente.

Estrutura de pastas

Cada cliente tem uma pasta própria no Google Drive/Workspace, com subpastas fixas: Documentos pessoais, Contratos, Comprovantes de pagamento e Correspondência com o órgão. Não crie estrutura própria fora desse padrão — isso quebra a organização para quem acessar depois de você.

Controle de acesso

O acesso às pastas de clientes segue a mesma lógica de equipes do portal: cada colaborador só deve ter acesso às pastas de clientes relacionados ao seu escopo de trabalho. Se notar uma pasta com permissão mais ampla do que deveria, avise a diretoria.

Documentos de clientes contêm dados pessoais sensíveis — nunca compartilhe um link de pasta ou arquivo fora do Workspace da empresa, mesmo que seja "só para adiantar" algo para o próprio cliente.
