Acompanhamento de status e comunicação com o cliente

Cadência de atualização

Todo caso em andamento deve receber uma atualização de status ao cliente pelo menos a cada 15 dias, mesmo que não tenha havido mudança ("seu processo continua em análise, sem novidades desde o último contato"). Se houver mudança de status, o cliente é avisado no mesmo dia.

Como responder sobre prazos

Prazos de processamento são estimativas do órgão emissor, não da consultoria. Use frases como: "o prazo médio informado atualmente pelo órgão é de X semanas, mas isso pode variar caso a caso", nunca uma data fechada.

Quando escalar para a diretoria

  • Cliente relata mensagem de recusa ou pedido de documentação adicional (RFE) do órgão.
  • Prazo estourou significativamente em relação à média informada.
  • Cliente demonstra intenção de reclamação formal ou insatisfação recorrente.
Regra de compliance: revise o Módulo 03 antes de qualquer comunicação de status — a mesma regra de não prometer resultado vale para atualizações de andamento.
