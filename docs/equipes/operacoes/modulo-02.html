Contratos: geração e envio

Como o fluxo funciona

Quando um cliente aceita um orçamento no Xero, um agente automatizado ("Contratos Enviados") gera o contrato a partir do modelo padrão da consultoria, preenchendo automaticamente os dados do cliente e do serviço contratado.

Seu papel na conferência

Antes de o contrato seguir para assinatura, confira:

  • Nome completo e dados do cliente idênticos ao cadastro no Xero.
  • Descrição do serviço e valor batendo exatamente com o orçamento aceito.
  • Cláusulas específicas do caso (se houver) preenchidas corretamente — o modelo padrão não cobre exceções automaticamente.

Envio para assinatura

Só depois da conferência o contrato é enviado para assinatura do cliente. Qualquer divergência encontrada deve ser corrigida antes do envio — nunca envie "para depois ajustar".

Contrato com erro em dados ou valor não é apenas um problema estético — pode gerar retrabalho jurídico e atraso no início do serviço.
