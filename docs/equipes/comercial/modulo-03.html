Script de qualificação em 6 perguntas

O script existe para você conseguir, em uma única conversa, entender se o lead está pronto para avançar e para qual serviço encaminhá-lo. As seis perguntas cobrem:

  1. Motivação — por que a pessoa quer se mudar/regularizar agora?
  2. País e via de interesse — já sabe qual caminho pretende seguir (trabalho, descendência, estudo) ou ainda está decidindo?
  3. Prazo desejado — tem uma data-limite (emprego já confirmado, evento de vida) ou é um projeto sem pressa?
  4. Situação documental atual — já tem documentos organizados, apostilados, traduzidos?
  5. Expectativa de investimento — a pessoa já pesquisou valores de mercado para esse tipo de serviço?
  6. Disponibilidade para agendamento — pode marcar uma consulta paga para aprofundar o caso?

Três variações de fechamento

  • Fechamento urgente — para leads com prazo apertado: foco em agendar a consulta o quanto antes para não perder a janela.
  • Fechamento consultivo — para leads ainda pesquisando: foco em educar e construir confiança antes de pedir o agendamento.
  • Fechamento por prova social — para leads indecisos: uso de cases e depoimentos para reduzir a incerteza.

O roteiro completo, com a redação exata de cada pergunta e variação de fechamento, está no documento "Script de Qualificação WhatsApp" — use este módulo para entender a lógica por trás de cada etapa.
